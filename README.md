# VexPlayer Modules

Public distribution of optional VexPlayer acoustic models. Packages are GitHub Release
assets; binaries are never stored in Git history. Machine-readable CTC catalog:
[ctc-models/catalog.json](ctc-models/catalog.json). Empty catalog means no verified
release has been published yet; no placeholder download links are advertised.

See ctc-models/docs for tensor format, model sources/licenses and reproducible packaging.
